Download Vagrant ISO from Vagrant cloud 

```

vagrant init ubuntu/jammy64
```
Now Power on the Vagrant 
```
vagrant up

```
To Check the Vagrant Sysytem Status
```
   vagrant status
```
To Check multiple Vagrant Status
```
     vagrant global-status
```
TO SSH to any vagrant 
```
vagarnt ssh
```
To turn off any Vagrant System
```
    vagrant halt
```
To Destroy any Vagrant
```
   vagrant destroy
```
